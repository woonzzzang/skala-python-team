## ✅ 해결된 논의 항목 (2026-07-22)

아래는 이전 버전에서 "팀 논의 필요"로 표시했다가, 팀 논의를 거쳐 결정하고 코드에 반영을 완료한 항목입니다.

1. **fnlwgt 모델 포함 (#16)** → 모델 feature에서 **제외**로 결정(표본가중치라 개인 예측 feature로 부적합). EDA·상관분석·시각화에는 그대로 사용.
2. **education·education-num 동시 사용 (#17)** → 모델에는 **education-num만** 사용하기로 결정. education은 EDA·시각화·해석 전용.
3. **income 타깃 문자열 유지 (#18, #40)** → 모델의 y만 **0/1로 매핑**하도록 변경(EDA는 문자열 유지).
4. **Pandas/Polars 실행시간 비교 없음 (#21)** → `time.perf_counter()` 기반 로드 시간, `memory_usage`/`estimated_size()` 기반 메모리 비교를 추가.
5. **ROC Curve 미시각화 (#24)** → `roc_curve.png` 추가.
6. **Plotly 차트 부족 (#26)** → 교육수준별/직업별 고소득 비율 막대 차트 2종 추가.
7. **클래스 불균형 처리 전/후 비교 없음, 모델 1개만 존재 (#38, #42)** → LogisticRegression(balanced)과 RandomForest(balanced)를 비교하고, `>50K` F1-score 기준(0.01 이내 동률이면 해석 가능성 우선)으로 최종 모델을 선택하는 규칙으로 통합 해결. 최근 실행에서는 F1 차이가 작아 LogisticRegression이 선택됨.
8. **카이제곱 workclass 누락 (#35)** → 4개 조합 모두 수행, Cramér's V 추가.
